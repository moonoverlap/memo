    메모를 불러오는 중 저장된 메모를 가져오고 있어요.
    메모 0개
    항상 위: Win+Ctrl+T공백 포함 0자공백 제외 0자

    메모를 골라 주세요왼쪽 목록에서 메모를 열거나, 새 메모를 바로 써보세요.

    동기화 · 설치

    계정

    계정으로 동기화 중이에요. PC와 폰에서 같은 계정으로 로그인하면 같은 메모가 보여요.

    로그인

    처음 쓰는 기기라면 계정 만들기, 이미 만든 계정이 있으면 같은 이메일로 로그인하세요.

    동기화 연결 (처음 한 번)

    무료 Firebase 프로젝트에 메모를 저장해 PC와 폰을 맞춰요. 한 번만 하면 됩니다.

    1. Firebase 콘솔에서 프로젝트를 만드세요. 쓰던 프로젝트를 써도 돼요.
    2. Authentication → 로그인 방법에서 이메일/비밀번호를 사용 설정하세요.
    3. Firestore Database를 만들고(위치는 asia-northeast3 서울 권장) 규칙 탭에 아래 규칙을 넣고 게시하세요. 쓰던 프로젝트라면 기존 규칙에 match /users/… 블록만 추가하세요.
    4. 프로젝트 설정 → 내 앱 → 웹 앱(</>)을 추가하고, 나오는 firebaseConfig를 아래 칸에 통째로 붙여넣으세요.
    rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{uid}/memos/{memoId} {
      allow read, write: if request.auth != null
                         && request.auth.uid == uid;
    }
  }
}

    앱으로 쓰기

    PC 바탕화면에 메모 띄우기

    새 창: 스티커 메모처럼 메모 한 장을 따로 떼어낸 창으로 열어요. 여러 장을 열어 바탕화면 원하는 곳에 둘 수 있고, 다음에 열면 같은 자리·크기로 열려요. 이 창들을 다른 프로그램 위에 계속 두려면 Windows의 PowerToys ‘항상 위에’ 기능(Win+Ctrl+T)을 각 창에서 누르세요.

    띄우기: 설치 없이 바로 다른 프로그램 위에 떠 있는 창 하나에 메모를 여러 장 나란히 넣어요. 메모마다 띄우기/내리기로 넣고 빼요. Chrome·Edge(PC) 기능이라 이 창은 한 번에 하나만 열리고, 메모앱 창을 닫으면 같이 닫혀요(최소화는 괜찮아요).

    띄운 창 크기

    항상 위 창과 새 창이 처음 열릴 때의 크기예요. 열린 창 모서리를 끌어 바꾸면 그 크기를 기억하고, 새 창은 메모마다 마지막 크기를 따로 기억해요.

    화면 밝기

    메모 종이는 고른 포스트잇 색 그대로 보여요.
